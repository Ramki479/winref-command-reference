PART A - COMMAND PROMPT (CMD)
=============================

SYSTEM & IDENTITY
-----------------
whoami                                          Prints the current security identity.                 # Confirm which account and domain context the foothold is using.
whoami /all                                     Shows SID, groups, privileges, and token details.     # Check the current token for useful group membership and enabled
                                                                                                      privileges.
hostname                                        Prints the computer name.                             # Record the target hostname before correlating it with domain and
                                                                                                      network data.
ver                                             Prints the Windows version.                           # Quickly identify the Windows release before selecting compatible
                                                                                                      checks.
systeminfo                                      Shows OS build, hotfixes, hardware, and boot details  # Fingerprint the host and record its patch and operating-system
                                                                                                      context.
query user                                      Lists interactive sessions visible on the local host  # Check whether other users have active or disconnected sessions.
set                                             Lists environment variables.                          # Inspect USERDOMAIN, USERDNSDOMAIN, LOGONSERVER, PATH, and
                                                                                                      application context.
echo %LOGONSERVER%                              Shows the logon server used for the current session.  # Identify the domain controller that authenticated the session.

USERS & GROUPS
--------------
net user                                        Lists local user accounts.                            # Enumerate local accounts during initial host discovery.
net user <username>                             Shows details for a specified local account.          # Review account status and metadata when an account looks
                                                                                                      relevant.
net user /domain                                Lists domain user accounts.                           # Enumerate domain identities from a domain-joined foothold.
net group "Domain Admins" /domain               Lists members of the Domain Admins group.             # Identify highly privileged domain membership using a read-only
                                                                                                      query.
net group /domain                               Lists domain groups.                                  # Build a first-pass view of groups exposed to the current domain
                                                                                                      user.
net localgroup                                  Lists local groups.                                   # Identify local groups that may control access to the host.
net localgroup Administrators                   Lists local Administrators group members.             # Check whether local or domain accounts have administrative
                                                                                                      access on this machine.

IMPORTANT NOTES
---------------
- Examples are intended for systems you own or are explicitly authorized to assess.
- Standard Windows commands are not guaranteed to return every detail; visibility depends on OS version, policy, and permissions.
- Get-AD* commands require the Active Directory PowerShell module (RSAT / AD DS tools). Get-GPO requires the GroupPolicy module.
- Some commands require Administrator privileges or feature-specific modules. A command being available does not mean the current account can read every object.
- Enumeration results are leads, not proof of a vulnerability. Validate permissions and configuration before drawing conclusions.
- Do not collect, expose, or reuse credentials or tokens outside the approved scope.
